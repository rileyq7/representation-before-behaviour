# Does occupational gender bias become linearly accessible before it becomes behaviourally observable?

Protocol v1, fixed 2026-09-21 before checkpoint inference. This is a local prospective analysis plan, not an externally registered preregistration.

## Source finding and scope

Patel et al., *Fairness Dynamics During Training*, reports a transition around 80k steps in **Pythia-6.9B**, using adapted WinoBias Type 2 prompts. It does not establish a transition in 1.4B. This project tests **EleutherAI/pythia-1.4b**, standard non-deduplicated, non-v0. A comparable transition must be discovered rather than assumed. The original paper already measures continuous probabilities; a discrete-metric artefact is a diagnostic, not a presumed explanation of their result.

Sources: https://arxiv.org/html/2506.01709v1 ; https://machinelearning.apple.com/research/fairness-dynamics ; https://github.com/EleutherAI/pythia ; https://github.com/uclanlp/corefBias/tree/master/WinoBias/wino/data . Local source copies and SHA-256 data manifest are in `sources/`.

## Measurements

1. **Matched primary extension:** 40 WinoBias occupations, with the dataset's 20 male-stereotyped / 20 female-stereotyped labels, crossed with six fixed gender-neutral continuation templates. No pronouns or gender labels occur in these inputs. Behaviour is log P(" she") minus log P(" he") at the final prompt position. Signed stereotype preference multiplies this difference by +1 for female-stereotyped occupations and -1 otherwise. Also report stereotyped two-choice accuracy, raw female preference, and female-vs-male occupation contrast so a general male prior is not confused with occupation association.
2. **Primary representation measure:** train a linear gender classifier on 10 explicit gender word pairs (e.g. father/mother), crossed with the same templates, and evaluate it on occupations. No occupation stereotype label is used in fitting this classifier. Hold out two templates at a time (three folds). Record accuracy and balanced accuracy (classes balanced), AUROC, and margins. Gender-word pair and template held-out validation checks whether the classifier learned transferable gender information. This operationalises alignment of occupation representations with an independently learned gender direction; it does not establish causal use.
3. **Secondary representation measure:** train a linear stereotype classifier directly on occupation activations. Simultaneously hold out occupation identities (five stratified folds) and template identities (three folds), with occupation-fold seeds 0, 1, 2. Report out-of-fold accuracy and AUROC. This tests decodability of externally assigned stereotype labels; it is weaker evidence of an intrinsic gender association.
4. **Apple-style behavioural reconstruction:** Type 2 WinoBias, both pro/anti splits, querying both the referenced occupation (male/female answer) and the unreferenced occupation (not specified answer). Reconstruct Figure 1 with ASCII punctuation. Score the first answer tokens male/female/not, restricted softmax, whole-vocabulary rank, accuracy, and JSD-P with natural logarithms. Five fixed option-order seeds in full data. Original authors' exact code, punctuation and seeds were not located, so this is a reconstruction, not an exact replication. A deterministic 16-pair development subset with one option seed is a discovery/feasibility measurement; never label it the full-paper evaluation.

## Layers and probes

Pythia-1.4B has 24 transformer blocks. Capture final prompt token at embedding output (layer 0), block outputs 6, 12, 18, and the final normalised output (24). Primary layer is **12**. Other layers are prespecified sensitivity analyses, not candidates from which to choose the most favourable onset. All probes use train-fold-only StandardScaler and logistic regression, C=0.01, liblinear, max_iter=1000, deterministic seed. No hyperparameter tuning on checkpoint results. Save convergence warnings. Do not train the language model.

Controls: step-0 random initialization; embedding layer at each checkpoint; 20 balanced noun-label permutations for the primary transfer classifier; occupation-label permutation controls for the direct classifier; held-out gender decoding; and character n-gram lexical baseline for direct stereotype decoding. Permutations preserve a noun's label across templates. A failed control yields an inconclusive representation result.

## Schedule and resources

There are 154 steps: 0, powers of two 1 through 512, and every 1000 through 143000. Start with final and step 0 for feasibility, then coarse steps 1000, 10000, 20000, 40000, 60000, 70000, 80000, 90000, 100000, 120000. Fill all remaining checkpoints for the matched experiment, preserving the same prompts and probe specification. The Apple discovery subset can be run at all checkpoints; the much larger full reconstruction is reserved for an independently specified bracket after discovery. Checkpoint spacing after 1000 limits onset precision to intervals, not exact training steps.

Mac M3, 16 GB shared memory. Float16 model inference, float32 saved activations and probe inputs. Batch size begins at 4. Official checkpoint .bin is about 2.93 GB; use modern PyTorch weights-only loading. Delete only the project's disposable checkpoint directory when changing steps, retaining metrics, provenance and activations. Full 154-step download traffic is approximately 450 GB. Disk headroom is checked before each download. Never change to a smaller model silently. A full sweep may take days locally; runtime will be estimated from actual measurements.

## Statistical analysis and decision rules

Occupation is the unit of resampling, not individual prompt. Use 2000 stratified occupation bootstraps (20 per class, with replacement), averaging templates within occupation. Report paired checkpoint differences against step 0 and shared bootstrap draws across time. Pointwise 95% intervals on plots are descriptive; onset decisions use a simultaneous max-deviation bootstrap band across **all 154 steps** for the prespecified primary layer/metric, separately for representation and behaviour. Seeds and templates are not independent datasets.

Operational representation onset: earliest checkpoint with transfer balanced accuracy lower simultaneous band >0.55, improvement over step 0 lower simultaneous band >0, and accuracy greater than every one of 20 permutation controls, sustained across three consecutive available checkpoints. The 20 permutations are a screening control, not a high-resolution multiple-testing-corrected p-value. Gender-word held-out decoding must exceed 0.8 at that checkpoint. Behaviour onset: signed stereotype log-odds lower simultaneous band >0.10 and improvement over step 0 lower simultaneous band >0, sustained for three checkpoints. These are practical thresholds, not universal definitions of latent bias. Report sensitivity to representation thresholds .50/.60 and log-odds thresholds .00/.20, without replacing the primary rule.

Compare onset **intervals** (last checkpoint failing the rule, first checkpoint passing it); a positive lead is supported only if representation's upper onset bound precedes behaviour's lower bound. Otherwise timing is unresolved at this resolution. If a metric never crosses, onset is right-censored; if already above threshold at initialization, it is left-censored and cannot establish learned emergence. Missing/partial curves never establish A or B. An overlapping interval permits 'no resolved lead', not proof of absence of earlier information.

Also report adjacent-step changes and a descriptive maximum-increment bracket on Apple-style JSD-P. A selected maximum does not itself establish a discontinuity. General male preference, occupation stereotype association, and pronoun-resolution fairness are related but distinct constructs; do not equate their onsets.

Full-reconstruction selection rule: after the 154-step discovery sweep, take the largest absolute adjacent change in the female-minus-male correct-answer JSD-P gap among steps 1000–143000. Evaluate the full reconstruction at both endpoints plus one neighbouring checkpoint on either side (up to four checkpoints). Report test-only results separately, with paired sentence-pair bootstrap intervals; this confirms or fails to confirm a selected change, not a discontinuity. WinoBias sometimes contains incidental third occupations or multiple coreferent pronouns: use its first two occupation mentions as the contrasted pair and validate all bracketed pronouns agree.

## Outputs and stopping

Immutable data manifests, checkpoint commit IDs, package lock, per-item logits/ranks, layer activations, per-fold predictions, controls, convergence warnings, figures, machine-readable status and a report. Synthetic fixtures validate software only and must never appear as empirical results. If resource or access limits prevent completion, report the exact completed checkpoints and remaining work; do not infer a lead from an unfinished sweep.
